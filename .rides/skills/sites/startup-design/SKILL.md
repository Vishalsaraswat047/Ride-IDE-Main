# Startup Design System

For pre-seed → Series A company sites: the site exists to (1) explain what you do in 5 seconds, (2) capture emails/waitlist, (3) convince investors/reviewers.

## Visual Direction
- Modern, minimal, confident. Neutral base + 1 bold accent (or mono/terminal aesthetic for dev tools).
- Editorial spacing; large clear type; real screenshots/product demo over stock art.
- Optional: subtle gradient mesh/aurora hero, kinetic type, scroll reveals — tasteful, not noisy.

## Layout (converting order)
1. Nav: logo + 3–4 links + CTA button.
2. **Hero = message + proof**: headline (what + who for + outcome), subhead (mechanism), CTA pair (primary action + secondary link), product demo/screenshot below.
3. Logos / "backed by" / press.
4. Problem section (before/after framing).
5. Product/demo section (screenshot/demo embed + 2–3 bullets).
6. How it works — 3 steps.
7. Metrics (real numbers: users, revenue impact, traction).
8. Testimonials (2–4, specific quotes).
9. Pricing or "coming soon" signup.
10. Final CTA (email capture).

## Rules
1. **Message-first**: every headline passes the elevator test — no vague "The modern platform for teams."
2. One message per section; one primary CTA per screen.
3. Waitlist signup: email (1 field) or email + use-case; confirmation page with clear next step.
4. Add "↳ Follow product updates" secondary capture at 60–70% scroll.
5. Keep JS light: image-heavy sections lazy-load; animations respect reduced-motion.
6. Placeholders: real logos/testimonials only; mark fictional with visible "(placeholder)".
7. Map features → benefits (don't list 20 features; list 5 benefits).

## Avoid
- ✗ Stock-photo hero with headline soup
- ✗ "Disrupting X" clichés
- ✗ Over-abundant gradients/glass everywhere
- ✗ Missing conversion element (every page needs a next step)
- ✗ Generic "team of 4 faces" footer without value

## CTA Patterns
- Waitlist button beat "Sign up" for pre-launch (lower commitment).
- Secondary: "Watch demo" / "Read announcement" video/marketing asset.
- Every section ends in a micro-CTA (arrow link), not buttons everywhere.
