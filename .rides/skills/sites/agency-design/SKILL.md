# Agency / Studio Design System

Agency sites convert visitors into a consultation request. Show craft BEFORE words.

## Visual Direction
- Premium editorial energy: generous whitespace, strong display typography (serif + grotesk OK), art-directed imagery, restrained accent color.
- Owning a "look" is the point — pick a distinctive typographic or chromatic identity and commit.

## Structure
1. Nav + oversized CTA ("Start a project").
2. Hero: craft-first (large project feature, kinetic marquee of capabilities, or strong statement + proof metrics).
3. **Work**: 4–8 flagship projects, visual-first grid/editorial columns; each → case study (brief, deliverables, results).
4. **Services**: 4–6 offerings framed as outcomes ("We build X for Y"), 2-column with short blocks — avoid icon soup.
5. Process: 4 steps (Discover → Design → Build → Launch) with concrete deliverables.
6. Team: real photos + one-line roles (or "our network" if freelancers).
7. Testimonials: client names + project context (photos help).
8. **Contact**: form (project type, budget range, timeline) + email; response promise ("48h reply").

## Lead-Gen Rules
1. Every page funnels to ONE inquiry CTA (hero + final + floating/sticky mobile).
2. Form: 4–6 fields max; budget + timeline selects narrow lead quality; trust microcopy ("We reply within 48h").
3. Social proof right before form (testimonials/logos).
4. Case studies include measurable outcomes (↑ conversions, ship time) — this is your lead magnet.

## Rules
- Real projects only; reuse the best 4–8, no filler.
- Avoid stock-behance-screenshot look: consistent art direction per project.
- Pricing: agencies rarely show — offer "guide/brief download" lead magnet instead.
- Motion: reveal-on-scroll + one signature interaction (marquee, parallax tilt on work cards). Reduced-motion safe.

## Checklist
- [ ] Work section shows results + process, not just pretty shots
- [ ] Form is short and framed with a next step
- [ ] Services named as outcomes
- [ ] Distinct identity (type/color) — not default template
- [ ] Mobile single column, images art-directed not cropped randomly
