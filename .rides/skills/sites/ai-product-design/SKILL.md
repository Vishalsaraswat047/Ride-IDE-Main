# AI Product Design System

## Visual Direction
- Premium, futuristic, technical, clean — strong typography, restrained palette with ONE signature accent.
- Allowed: cinematic hero, product visualization (live input/output), subtle motion, interactive demo, animated gradients (accent only), glass panels (tasteful).
- Avoid: excessive gradients, generic card grids, emoji icons, excessive glassmorphism, random animations, enormous text everywhere.

## Structure (canonical AI startup)
1. Nav: product, features, pricing, docs, API, login + CTA.
2. **Cinematic hero**: punchy outcome headline + LIVE product interaction (chat demo, model output streaming, image generation preview) — never just a card mockup.
3. Social proof (logos, "built by", press).
4. **Product visualization**: side-by-side before/after, latency demo, live streaming output.
5. Feature architecture: 3–5 sections explaining the pipeline (input → model → output), NOT generic feature cards.
6. Interactive demo block (try it inline: prompt → result with fake latency).
7. Technical credibility: model specs, benchmarks table, API code snippet (`curl` example), open-source links.
8. Pricing (per-seat / per-token / hybrid — show both).
9. FAQ + docs links + final CTA.

## AI-Specific Rules
1. **Show the machine thinking**: streaming output, token-by-token reveal, "thinking…" states — these sell AI products better than copy.
2. Chat UI: user bubble + assistant bubble, markdown/code rendering, suggested prompts row, typing indicator, regenerate button.
3. Treat every AI output as potentially wrong: "AI can make mistakes" disclaimer, verify button, feedback thumbs.
4. Status: model running/queued states MUST be visible (no dead buttons).
5. Benchmarks vs. competition table (if honest) — credibility wins.
6. Interactive demo must be fast (fake it well) and work without signup.
7. Cap reuse: 3D/particles optional hero garnish — not required for quality.

## Motion
- Hero reveal (staggered), scroll-driven sections, hover micro-interactions, streaming dots animation — all ≤ 0.6s, reduced-motion safe.

## Avoid
- ✗ Purple gradient EVERYWHERE
- ✗ Emoji robot icons for features
- ✗ "AI-powered" on every line (say what it DOES)
- ✗ Static chatbot screenshot as the whole hero
- ✗ Claiming AGI
